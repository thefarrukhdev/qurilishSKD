# UrbanPulse Samarqand — AI va Sun'iy Yo'ldosh Monitoringi Platformasi

UrbanPulse Samarqand — sun'iy yo'ldosh tasvirlari, drone monitoringi va sun'iy intellekt texnologiyalarini birlashtirgan shahar infratuzilmasi hamda qurilish loyihalarini avtomatlashtirilgan tarzda kuzatuvchi GovTech/CivicTech platformadir.

## 🚀 Loyiha Haqida

Platformaning maqsadi Samarqand shahri va uning atrofidagi qurilish loyihalarini inson omilisiz, obyektiv va shaffof monitoring qilishdir. Sentinel va Landsat kabi ochiq ma'lumotlar manbalaridan olingan yo'ldosh tasvirlari sun'iy intellekt yordamida tahlil qilinadi.

### 🌟 Asosiy Xususiyatlari
* **Avtomatik Sun'iy Yo'ldosh Monitoringi:** Inson omilisiz shahar qurilishlarini tahlil qilish.
* **Real Vaqtli AI Tahlili:** Infratuzilmadagi o'zgarishlar va kechikishlarni tezkor aniqlash.
* **Shaffof Fuqarolik Dashboardi:** Aholiga shahar byudjeti va qurilish jarayonlarini ko'rish imkonini beruvchi interfeys.

## 🛠 Texnologiyalar
* **Web Frontend:** Next.js, React, TailwindCSS, TypeScript.
* **AI Service:** Python, Jupyter, Machine Learning modullari.
* **Backend:** Python API & Ma'lumotlar bazasi integratsiyasi.
